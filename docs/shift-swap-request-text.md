## The 4-Part Formula (works for almost any swap text)

1. **Warm greeting** — name them, keep it human.
2. **The specific ask** — exact date, exact shift, no vague "sometime this month."
3. **What you offer** — a trade, a favor, or flexibility on your end.
4. **An easy out** — make "no" feel completely okay. Kind asks get more yeses.

> **Copying tip:** Replace every `[bracketed placeholder]` with your own details.
> These are deliberately neutral — no facility names, no unit inside jokes.

---

## Script 1 — The General Ask (group text / team chat)

```
Hey! Anyone want to trade a shift with me? I'm hoping to swap my
[Wed 10/14 7p-7a] for a [day] shift that week. Happy to take a
weekend or a night in return — just tell me what works!
```

## Script 2 — Asking One Reliable Person

```
Hi [Name]! I hate to ask, but you're the first person I thought of.
Any chance you'd want to swap my [Tuesday 3/5 day] for one of your
shifts later that same week? I can flex to whatever works best for
you — and obviously no worries at all if it doesn't line up.
```

## Script 3 — The Emergency Swap (sincere, no drama)

```
[Name], I have an emergency at home and need someone to cover my
[Friday night] shift. I'd be so grateful — I'm happy to take one of
yours whenever it works, or count it as a favor you can call in
anytime. If it can't work, no hard feelings, I'll keep looking.
```

## Script 4 — Offering a Shift First (swap disguised as kindness)

```
Hey [Name] — I noticed you've got school stuff going on around
[Nov 20]. I'm free that day and my schedule is quiet that week —
want me to pick up your shift, and you could cover one of mine
another time? Zero pressure either way!
```

## Script 5 — The Gentle Follow-Up (once, then let it go)

```
Hi [Name], floating this back to the top of your messages in case
you missed it — no stress either way, I know your week is packed.
If it's a no, just tell me and I'll ask around.
```

## Script 6 — Answering "Can you cover me?" with a trade

```
I can take [Saturday] for you — could we make it a swap instead?
You'd cover my [Wednesday] the week after, which would actually
help me out a ton.
```

## Why these work

- **Specific dates** reduce the "I'll think about it" limbo.
- **A named trade** answers their silent question: *what's in it for me?*
- **The easy out** protects the relationship, which matters more than one shift.
- **Once-and-done follow-ups** keep you from becoming "that person."
